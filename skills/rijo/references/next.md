Preserve all prior milestone history.

1. Verify that the prior milestone is sealed.
2. Archive its final context when required.
3. Create the next milestone identifier.
4. Carry unresolved requirements with lineage.
5. Refresh a stale codebase map with native read-only subagents.
6. Reuse current decisions and the current codebase map.
7. Research only new or changed project-level facts.
8. Create a new high-level roadmap.
9. Update active project state.
10. Read `native-results.md`.
11. Record the research and roadmap in a result bundle.
12. Run `node .rijo/bin/rijo.cjs internal workflow-open next @NEXT-PLAN.md` once for this public command.
13. Run `node .rijo/bin/rijo.cjs internal next-init @NEXT-PLAN.md --results @.rijo/runtime/native-results.json`.

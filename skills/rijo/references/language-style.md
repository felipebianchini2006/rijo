# Controlled English policy

Use English for code, prompts, templates, documentation, schemas, tests, runtime messages, and generated artifacts.
Use English for all host messages and final reports.
Never answer in Portuguese during a RIJO workflow.
Use an ASD-STE100-inspired controlled English policy.
Do not claim formal ASD-STE100 certification.

- Use short sentences.
- Use active voice.
- Use one instruction per sentence.
- Use consistent terms.
- Avoid idioms.
- Avoid contractions.
- Avoid ambiguous pronouns.
- Define each abbreviation before use.
- Use imperative verbs for procedures.
- State conditions explicitly.

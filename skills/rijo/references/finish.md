# Finish a milestone

Do not implement missing work in this workflow.

1. Verify that every roadmap phase is complete.
2. Verify that every requirement has evidence.
3. Verify that full product testing has a terminal result.
4. Verify that the tested commit is recorded.
5. Verify that no supervised task is active.
6. Verify that the working tree is clean.
7. Refuse to continue when any check fails.
8. Write `CLOSEOUT.md`.
9. Seal the milestone.
10. Archive detailed phase artifacts.
11. Keep active context small.
12. Update `.rijo/STATE.md`.
13. Run `rijo internal milestone-finish` to validate and persist the sealed milestone.
